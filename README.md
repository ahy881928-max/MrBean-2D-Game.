# Mr Bean 2D Adventure (Godot 4.7.2)

A small playable 2D prototype made with Godot. It uses simple shapes drawn by code, so no external art assets are required.

## Open the project
1. Download/extract this folder.
2. Open Godot 4.7.2.
3. Import the folder containing `project.godot`.
4. Press **Run Project**.

## Controls
- Keyboard: Arrow keys or WASD.
- Touch: tap/hold the left, right, up, or down screen areas to move.
- Collect all 8 teddy bears, then reach the green EXIT.

## Important
This is a starter prototype, not a finished commercial game. The character is a simple original cartoon approximation made from shapes. Android APK export requires the Godot Android export templates and Android export setup.
